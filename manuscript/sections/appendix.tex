\section{Reproduction}
\label{sec:repro}

Every experiment is defined by a specification file and started by a request file in the repository; it runs on
hosted runners, publishes its raw logs, and records a hash of each run's logs. Running a specification again with the
same code revision reproduces the hashes. The public datasets are fetched by scripts that record the source, the
retrieval time and the checksum of each input and derived file. The calibration measurements of each machine are
committed with the machine's specification and the versions of every tool used.
